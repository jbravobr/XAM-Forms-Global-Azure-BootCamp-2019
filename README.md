# Xamarin.Forms — Global Azure BootCamp 2019

> Demonstração Xamarin.Forms apresentada no Global Azure BootCamp 2019.

## Organização

- `GAB.Android/` — projeto ou módulo `GAB.Android`.
- `GAB.iOS/` — projeto ou módulo `GAB.iOS`.
- `GAB/` — projeto ou módulo `GAB`.

Solução: [`GAB.sln`](GAB.sln).

## Tecnologias

C# e .NET.

## Como abrir

Abra [`GAB.sln`](GAB.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
